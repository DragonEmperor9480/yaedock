YaeDock 0.5.1 gives the phone back its USB file transfer when the cable setting is off.

## Fixed

### File transfer with the cable setting off
Before, a phone that had used the cable once was switched to it every time it was plugged in, even with **Use the USB cable** turned off in the app. The phone's file transfer stayed off, and Android kept asking to open YaeDock or showed "No installed apps work with this USB accessory". Now:
- **Setting off:** Android asks nothing, and the PC leaves the phone alone, so file transfer works as soon as it's plugged in.
- **Turned off away from the PC,** with no Wi-Fi to tell it: the next plug-in waits about 15 seconds once, with nothing on screen, then the phone is back to file transfer and stays that way.
- **The app not using the cable for any reason,** such as being closed: the PC lets the phone go after 15 seconds instead of holding it.

## Good to know

- **Using the cable again:** turn **Use the USB cable** back on, then either plug in while the app is connected over Wi-Fi, or run `yaedock pair` on the PC with the phone plugged in. The phone keeps its pairing; the PC only relearns it on the cable. The setting says this too.
- **Android's prompt:** with the setting on, tick "Always open YaeDock when … is connected" on Android's prompt, so it doesn't ask each time. If the prompt goes unanswered for 15 seconds, the PC lets the phone go.

## Updating

- **PC:** run `yaedock update`, or use **Check for updates** in the `yaedock` menu, or update it from the app.
- **App:** go to About → Updates.

Update both: the PC stops holding the phone, and the app stops Android asking.
